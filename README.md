# Brew & Bean — Coffee Ecommerce Frontend

A React + Vite storefront for a small-batch coffee roaster.

## Features
- Product catalogue: beans, brewing gear, cold brew and treats, with real photos and tasting notes
- Search, category filters and sorting
- Product options (grind / size / colour), quantity picker, wishlist
- Cart with promo codes (`BREW10`, `FREESHIP`), persisted in localStorage
- Checkout with form validation and order confirmation (demo — no payments)
- Responsive layout

## Run
```bash
npm install
npm run dev     # http://localhost:5173
npm run build   # production build in dist/
```

## Stack
React 18 · Vite · React Router · plain CSS
